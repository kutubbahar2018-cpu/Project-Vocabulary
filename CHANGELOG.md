# Changelog

All notable changes to Posh are listed here, newest first.

## Latest
- Share button in the app, so learners can send the link to friends.
- Link previews: shared links show the name, description and icon.
- Backup and restore of progress from Settings.
- Privacy page and feedback link.
- New Posh logo and icons, with a deep ink teal colour scheme.
- Session button now shows how many cards the session covers and how many are due.
- Short link (`/posh/`) that opens the app.

## Earlier
- Levels from easiest to hardest, with quizzes after each level.
- Active recall with a progress page.
- English and বাংলা switch.
- Works offline and can be installed on a phone or computer.
